# Цель проекта:

___Создать новый модуль в проекте decorators, который будет использоваться 
для размещения декораторов, включая декоратор log.___

## Инструкция и использование:
В модуле декоратор log:
* автоматически логирует начало и конец выполнения функции
* ее результаты или возникшие ошибки
* принимает необязательный аргумент, который определяет, куда будут записываться логи
(в файл или в консоль)

## Примеры использования декоратора:
* вывод в лог-файл mylog.txt при успешном выполнении
~~~
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

print("1. Успешное выполнение (mylog.txt):")
result1 = my_function(1, 2)
print(f"   Результат: {result1}")
~~~
* вывод при ошибке
~~~
@log(filename="error_example.txt")
def error_function(x, y):
    return x / y

print("\n3. Ошибка выполнения (файл error_example.txt):")
try:
    error_function(10, 0)
except ZeroDivisionError:
    print("   Ошибка перехвачена: ZeroDivisionError")
~~~
